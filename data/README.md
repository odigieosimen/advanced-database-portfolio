# Data

Data files are **not committed** to GitHub (see `.gitignore`).

## Dataset
**Brazilian E-Commerce Public Dataset by Olist** (Kaggle), around 100k orders across 9 related CSV files.
Licence: CC BY-NC-SA 4.0. Cited in the main README.

## How to reproduce
1. Download the dataset zip from Kaggle.
2. Extract the CSV files into `data/raw/` on your machine.
3. Load them into MySQL following `P1-database-design/README.md`.
