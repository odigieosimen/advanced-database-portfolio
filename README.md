## 1. Selected Case Study

**Organisation / scenario:** Olist-style online marketplace (simulated e-commerce platform), based on the public Olist Brazilian E-Commerce dataset.

**Nature of the system:** An online marketplace where sellers list products and customers place orders, pay, and receive deliveries.

**Users of the database:** Customers, sellers, platform administrators, and analysts.

**Major data stored:** Customers, sellers, products, orders, order items, payments, reviews, and delivery records.

**Key operations supported:** Add products, place orders, update stock, process payments, track delivery, and report on sales.
