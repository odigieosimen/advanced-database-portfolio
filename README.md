# advanced-database-portfolio
MIT 8103 Advanced Database Systems Project, Miva University

This repository contains projects exploring core topics in advanced database
systems.

## Projects

- [P1: Database Design](P1-database-design/) - Data modeling, schema design, and normalization.
- [P2: Query Optimisation](P2-query-optimisation/) - Query plans, indexing, and performance tuning.
- [P3: Transactions and Concurrency](P3-transactions-concurrency/) - Transaction processing, isolation, and concurrency control.
- [P4: NoSQL](P4-nosql/) - Non-relational data models and database systems.
- [P5: Distributed and Cloud Databases](P5-distributed-cloud/) - Distributed data, consistency, and cloud database architectures.
